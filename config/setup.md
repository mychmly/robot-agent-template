# setup.md

## 文档用途

本文件用于说明第一次把模板跑起来前需要完成哪些步骤。

它只负责“怎么配起来”，不负责 Agent 行为逻辑。

## 当前状态提醒

当前版本已经接入最小 Next.js + 本地 Markdown 文件系统骨架。

## 1. 本地启动前需要完成的步骤

1. 准备 AI 编程工具，例如 Cursor
2. 从仓库获取当前分发版本
3. 阅读 `config/model.md`
4. 根据 `.env.example` 生成本地 `.env`
5. 执行 `npm install`
6. 执行 `npm run dev`

## 4. 遇到常见报错时先检查什么

- 是否已经正确生成 `.env`
- API key 是否填写完整
- 模型名称是否填写正确
- 本地依赖是否已安装
- 启动命令是否与底座项目一致

## 5. 当前课堂最低启动路径

- 先完成模板阅读与配置准备
- 在当前目录执行 `npm install`
- 根据 `.env.example` 生成 `.env`
- 填入 API key 与模型信息
- 执行 `npm run dev`
- 先保证本地最小演示可以跑通，再继续扩展
