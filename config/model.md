# model.md

## 文档用途

本文件用于说明这个模板最低需要什么模型能力，以及应该申请哪类 API key。

## 1. 当前最低需要的模型能力

- 文本理解与生成：必需
- 图片理解：必需
- 音频转写 / 理解：选配
- 外部工具结果整合：建议支持

## 2. 统一多模态模型对应什么

- 当前模板默认采用单一统一多模态模型，同时处理文本和图片输入
- 它至少需要支持：
  - 中文理解
  - 结构化结果生成
  - 图像内容识别
  - 图像与文本联合理解

## 4. 音频能力当前状态

- 当前状态：预留接口
- 第二讲课堂内不要求必须启用
- 若后续启用，需要补充语音转写或音频理解能力

## 6. 当前建议的默认配置

- `BASE_URL`：`https://dashscope.aliyuncs.com/compatible-mode/v1`
- `MODEL`：`qwen3.6-plus`

若默认 `Qwen` 路线因账号、配额或调用稳定性受阻，课堂内唯一备选为豆包多模态路线。

## 6-1. 当前第一批基础外部工具路线

- `time_now`：本地系统时钟
- `current_location`：位置状态源 / 视觉 fallback
- `weather_lookup`：外部天气服务
- `home_environment_status`：环境状态源
- `web_search`：仅在用户显式提问时触发的受控检索能力

当前提醒：

- 外部工具不是为了把当前模板变成通用助手
- 工具只服务时间、空间、天气、环境状态和基础常识问题

## 7. 课堂不要求配置的能力

- 数据库
- 向量数据库
- 线上部署密钥
- 用户权限系统
- 多用户管理能力
